# 小灶 · 做饭新手助手

手机优先的中文做饭 App，支持网页使用与安卓 APK 安装。从手边食材出发，选一餐、扫一眼备料、整页跟做。无账号、无业务后端，不调用 AI 服务。

## 最新 Web 迭代

新增 **11 道国内原站教程复核**：优先呈现下厨房作者的具体教程、采用技法和小灶的改写差异，另给凉拌木耳补香港食安中心泡发依据。不是把海外链接换个名字，也不把站内热度冒充本项目验证；原有出处保留。同步细化拍黄瓜的少盐与安全轻拍、包菜提前备调味、香菇蒸鸡单层铺盘、木耳泡好尽快煮、麻婆豆腐酱料切细。只有这 11 道完成本轮国内原页复核，不声称 99 道全量国内验证。见 [国内来源复核与取舍](docs/DOMESTIC_RECIPE_REVIEW.md)。

跟做页先看实际步骤：将较长的做菜要点、补救和厨房小抄放到步骤之后，备料页仍保留完整提醒；用量、常亮、当前计时依然可用。保留整页模式、已有步骤位置和计时，不强制新增操作。

菜篮新增「帮我排个顺序」：先看开火前准备、逐菜理由和粗略用时，点采用才改变菜篮，也能撤销和手动调整。当前一餐与计时不受影响，仍做完一道再做下一道，不安排跨菜穿插。排序只用已核对的菜谱步骤依据；10 道有明确先后建议，19 道有准备提醒（合计覆盖 25 道），其余保留相对顺序，不靠菜名猜标签。见 [顺序建议说明](docs/MEAL_ORDER_PLANNING.md)。

**99/99 道已完成新手教学改写**：把“什么时候做下一步”写成可观察的状态，每道有重点、灵活用量和具体补救，共 201 条补救建议。综合公开教程与食安指引，优先采用能核实的读者反馈；部分原链接本轮不可读或只核对到相近技法，均明确记录，不声称 99 道都是实时高赞榜单。保留步骤顺序、跟做进度和计时，调整/补救默认折叠。全部尚未下厨试做。见 [批量范围与证据边界](docs/RECIPE_TEACHING_BATCH.md)。

最新交互调整：把设置里的“今天重新选食材”移到菜篮，保留调料、已选菜和跟做进度；与首页清空入口共用撤销。食材输入框只通过右侧箭头展开建议，输入和聚焦不再自动弹出；支持键盘、别名和批量输入。详见 [测试记录](docs/TEST_REPORT.md)。

源码仓库：[lotus116/xiaozao](https://github.com/lotus116/xiaozao)。本次已整合 99 道教学内容与菜篮顺序建议。此前面向真实灶台使用，修正 11 道菜的清水量、备料顺序、火力和食安细节，新增非强制开火前提醒、整页步骤位置记忆、可选屏幕常亮、当前计时就地查看和折叠厨房小抄。保留整页看、少操作、99 道菜及米白/锅绿风格。

见 [本轮研究与设计取舍](docs/REAL_COOKING_ITERATION.md)、[菜谱内容审计](docs/COOKING_CONTENT_AUDIT.md) 和 [测试记录](docs/TEST_REPORT.md)。本轮没有重新生成安卓 APK，也没有发布公开网站。

## 安卓安装

上一轮安装包（不含最新 Web 改动）：`releases/xiaozao-1.1.0-debug.apk`。将文件传到 Android 7.0 及以上手机，在文件管理器中打开安装。99 道菜谱已打包，安装后无需电脑或联网即可查看。此包为测试签名，未上架、未做安卓真机测试。详细安装、数据保存和重新打包方式见 [安卓说明](docs/ANDROID.md)。

## 本地运行

需要 Node.js 22.12+（本轮使用 24.21.0；安卓工具要求 Node.js 22+）。在项目目录执行：

```sh
npm ci
npm run dev
```

打开终端给出的地址，默认 http://localhost:5173 。同一 Wi-Fi 的手机可打开终端显示的 Network 地址；电脑需保持运行并允许本地网络访问。若端口被占用，以终端实际地址为准。

生产预览：

```sh
npm run build
npm run preview
```

默认 http://localhost:4173 。构建产物位于 `dist/`，可部署到普通静态站点；已完成的版本可在 GitHub 查看；当前国内来源迭代的验证与发布状态见测试记录，尚未公开部署网站。

## 已实现

- 手动食材输入、快捷选择、别名归一化、去重与删除；支持顿号/逗号/空格批量添加及多行粘贴，清空本次食材可撤销；常备调料选一次即保存，清空本次食材时继续保留。
- 常用食材可添加、取消、拖动排序，也支持上下按钮和键盘；自动记住个人名单与顺序，支持恢复默认。常用名单与今天的食材独立保存。
- 更多食材按蔬菜菌菇、肉类、鱼虾海鲜、豆制品、蛋奶、米面主食、半成品、水果及其他分类；支持别名搜索，自定义食材也可以加入常用。
- 食材种类齐全 / 缺 1–2 样分组，全部必需缺料列出，可选配料不阻断。
- 99 道精选家常/懒人菜：70 道菜肴、18 道主食、11 道汤羹，分开浏览和推荐；支持菜名/食材、时间、难度、5 项以内必需用料筛选。
- 本轮新增 46 道、简化 43 道旧菜。97 道不超过 5 项必需用料（计油盐，不计水）。番茄蛋花汤只需番茄、鸡蛋、油、水、盐；可省配料有用途说明，步骤同步调整。
- 厨房设置：10 类常见过敏筛选，自定义普通忌口可选隐藏或提醒；过敏限制也应用于直接链接。
- 标准份数、用量、厨具、营养参考、来源与未试做声明；99 道均有具体教学重点、可调整范围及折叠补救，关键食安同时保留在主步骤中。
- 备料是图标、名称、用量组成的提醒卡片，分主料/基础调味/可选配料，无需逐项打勾。开火前提示洗切、分装和生熟分开；跟做默认整页看，也可切换分步看，点击步骤序号可记住当前位置。
- 底部菜篮：选菜、移除、顺序建议预览/采用/撤销、手动调整顺序、集中备料、缺料速览及本机复制采购文本、一键开始一餐，完成一道后接着下一道。过敏限制也应用于菜篮；开做后菜单顺序保留为当前一餐，修改菜篮不打乱进行中的一餐。
- 本机食材、收藏、偏好、菜篮、当前一餐和跟做进度保存。纯图标计时入口可拖动、长按隐藏，位置与隐藏状态保存，设置中可恢复。键盘方向键移动，Home 复位，也提供点击位置按钮。
- 计时器支持自定义、暂停/继续、加一分钟。结束计时会关闭弹层、留在原页；隐藏图标不会取消计时，到点仍显示可关闭的可视提醒。单个全局计时器按结束时间恢复，刷新后可继续。
- 可选跟做屏幕常亮，只在用户主动开启后请求；失败/不支持/系统释放如实显示，离开释放。折叠厨房小抄提供量勺、份数、火候和计时原则。
- 中文响应式布局，自绘碗盘示意，键盘焦点与可访问标签。

## 3–5 分钟演示

1. 输入“西红柿”，再输入“番茄”，观察别名合并。
2. 添加鸡蛋，在常备调料中选食用油、盐；无需选白胡椒、料酒、香油、糖或葱。
3. 点菜谱旁的菜篮，加入番茄炒蛋和另一道菜；底部进入菜篮，集中看用量，一键开始做饭。
4. 整页查看步骤，无需勾选备料或频繁翻下一步。点悬浮时钟设置 3 分钟；结束计时留在做菜页。拖动图标、长按隐藏，再到设置恢复。
5. 完成一道后点“下一道”，做完这一餐。刷新确认菜篮/收藏/调料保留；切换菜肴、主食和汤羹，试用“少配料”筛选。

## 真实限制

- 尚未实际试做。99 道是网页资料核对及编辑简化后的笔记，不是厨房实测结果。
- 以 1–2 人份为主，未自动缩放份数。总耗时包含编辑估计；少配料不代表时间一定短，例如炖汤、焖饭仍需等待。菜篮保留每道菜的用量，不把“少许”和克数强行相加。
- 营养是原作者估算，部分菜未展示数值。来源、版本差异和使用条件见 [来源记录](docs/RECIPE_SOURCES.md)。
- 清单只记种类，不记重量、保质期；不自动推断替代食材。过敏筛选根据列出的原料与部分复合调味品规则，无法保证品牌配方或交叉接触安全，实际仍需核对包装。
- 网页本地保存仅限同一浏览器、同一来源地址；安卓 App 独立保存。清理数据或卸载会丢失，不跨设备同步。
- 计时只有页面内提醒，不保证锁屏/后台声音或系统通知；长炖请同时设手机系统计时器。跟做页可主动请求常亮，但依赖浏览器/系统支持且可能被释放，失败会说明。安卓已内置菜谱、支持首次离线打开；网页版尚未添加离线缓存。
- Chromium 模拟手机尺寸通过不等于 iOS/Android 真机测试，用户仍需在实际手机检查触控与课程演示网络。
- 拍照识别、模型训练、账号、社区和公开发布不在本轮范围。

## 文件结构

`src/recipes.js` / `src/extra.js` / `src/chinese-recipes.js` / `src/easy-recipes.js`：基础菜谱与来源；`src/beginner-recipes.js` / `src/teaching-*.js`：兼容旧进度的新手教学；`src/preferences.js` / `src/Settings.jsx`：偏好；`src/TimerWidget.jsx`：悬浮计时器；`src/Ingredients.jsx`：备料卡片；`src/Basket.jsx` / `src/meal.js`：菜篮与整餐；`src/MealPlanner.jsx` / `src/meal-planning.js` / `src/meal-planning-data.js`：顺序预览、证据验证与准备提醒；`src/Cooking.jsx`：跟做；`src/domestic-sources.js` / `src/RecipeSources.jsx`：国内原站参考与逐菜取舍；`src/logic.js`：匹配与存储；`tests/`：规则与浏览器验收。
