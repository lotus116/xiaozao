# 小灶 · 做饭新手助手

当前阶段版本 **1.6.3**（Android versionCode 12）。React + Vite + Capacitor 安卓应用，免登录、无业务后端；200 道菜、625 个步骤和照片随 APK 离线提供。

[下载阶段发布](https://github.com/lotus116/xiaozao/releases/tag/v1.6.3) · [文档索引](docs/INDEX.md) · [当前 PRD](docs/PRD.md) · [安卓安装](docs/ANDROID.md) · [测试记录](docs/TEST_REPORT.md)

## 当前功能

- 手动／批量添加食材，别名归一、去重、常用食材与常备调料；未收录和需细分状态持续显示。
- 根据已有主料推荐齐料或缺 1–2 样的菜。“不限食材”是不指定必须用到哪种已有食材，仍按库存推荐；选择某种食材后只保留用到它的推荐。
- 菜名、食材与别名跨分类搜索；收藏、分类、时间、难度、少配料和饮食限制筛选。
- 菜篮排序、备料、采购清单和顺序建议；当前一餐保留菜单快照，返回／刷新保留进度，误点完成可恢复待做。
- 整页／分步跟做，有依据才显示本步用量、火力和状态；不强制勾选备料。
- 全局悬浮计时器可拖动、长按隐藏、设置恢复；暂停、加时、前台响铃及试听／关闭。隐藏不结束计时。
- 可选跟做常亮与失败提示、本地保存。A「小字蒸汽锅」标志，轻量顶部找菜／设置入口，底部四项导航。
- 原有暖白、番茄红、深棕与现有菜品照片；安卓安全区和手机横竖屏适配。

## 安装与运行

Release 附件为 `xiaozao-1.6.3-debug.apk` 和 SHA-256 文件，Android 7.0+ 可安装。沿用原测试签名，可覆盖旧测试版本；不要先卸载，以免丢失本地数据。这是课堂演示测试包，非商店正式签名包。

开发需要 Node.js 22.12+：

```sh
npm ci
npm run dev
```

生产构建／预览：`npm run build`、`npm run preview`。安卓构建：`npm run android:apk`；项目本地 JDK 21 与 SDK 36 已就绪，见[安卓说明](docs/ANDROID.md)。

## 验证与限制

1.6.3 已通过 **98 项单元测试、409 项生产浏览器测试**；Android lint 0 错误、5 项已有警告。额外检查四种手机尺寸、触点、安全区、搜索条件与历史返回，见[测试记录](docs/TEST_REPORT.md)。

```sh
npm test
npx playwright install chromium
npm run test:e2e
```

- 手机浏览器模拟不等于安卓真机验收；厂商桌面、真实扬声器及后台行为仍待确认。
- 后台／锁屏提醒、拍照识别、账号、同步、社区尚未实现。网页没有离线缓存；APK 可首次离线打开内置内容。
- 全部 200 道目前没有营养估算值，也未由项目逐道下厨验证。用量、耗时和配方包含编辑取舍。
- 库存只记种类，不记重量、保质期；过敏筛选不能替代包装与交叉接触检查。
- 数据仅保存在各设备／浏览器本地，卸载或清理会丢失，无云备份。
- 照片与做法逐项署名，公开来源不等于无限转载授权。部分照片用于非商业课程演示，商业使用须另核对许可，见[来源清单](docs/RECIPE_SOURCES.md)与[200 道研究](docs/EXPANDED_200_RESEARCH.md)。
