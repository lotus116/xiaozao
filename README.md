# 小灶 · 做饭新手助手

手机优先的中文 Web App。从手边食材出发，找菜谱、核对用量、分步跟做。无账号、无业务后端，不调用 AI 服务。

## 本地运行

需要 Node.js 20.19+ 或 22.12+（本轮使用 24.21.0）。在项目目录执行：

```sh
npm ci
npm run dev
```

打开终端给出的地址，默认 http://localhost:5173 。同一 Wi-Fi 的手机可打开终端显示的 Network 地址；电脑需保持运行并允许本地网络访问。若端口被占用，以终端实际地址为准。

生产预览：

```sh
npm run build
npm run preview
```

默认 http://localhost:4173 。构建产物位于 `dist/`，可部署到普通静态站点；本轮未公开部署或推送远端。

## 已实现

- 手动食材输入、快捷选择、别名归一化、去重与删除；常备调料选一次即保存，清空本次食材时继续保留。
- 食材种类齐全 / 缺 1–2 样分组，全部必需缺料列出，可选配料不阻断。
- 53 道有可追溯来源的菜谱：37 道菜肴、11 道主食、5 道汤羹，分开浏览和推荐；搜索菜名/食材、筛选时间与难度。
- 新增 26 道中文家常菜，重整 4 道已有菜。可省配料注明原因，步骤同步说明；番茄炒蛋只需番茄、鸡蛋、油、盐。
- 厨房设置：10 类常见过敏筛选，自定义普通忌口可选隐藏或提醒；过敏限制也应用于直接链接。
- 标准份数、用量、厨具、营养参考、来源与未试做声明。
- 备料勾选后进入分步跟做，前后切换，主动启动计时，完成页。
- 本机食材、收藏、偏好、备料和跟做进度保存。悬浮计时器支持自定义名称与时长、暂停/继续、加一分钟。单个全局计时器按结束时间恢复，刷新后可继续；过期显示检查提醒。
- 中文响应式布局，自绘碗盘示意，键盘焦点与可访问标签。

## 3–5 分钟演示

1. 输入“西红柿”，再输入“番茄”，观察别名合并。
2. 添加鸡蛋，在常备调料中选食用油、盐；无需选白胡椒、料酒、香油、糖或葱。
3. 点击“看看能做什么”，打开番茄炒鸡蛋，检查缺料与用量。
4. 收藏，进入备料，只勾必需食材后开始跟做；点“随手计时”设置 3 分钟，再切换页面并刷新。
5. 走完步骤，回到厨房；切换菜肴/主食/汤羹。进入设置选“蛋类”，验证蛋类菜被排除，清空本次食材仍保留油盐。

## 真实限制

- 尚未实际试做。53 道是网页资料核对及编辑简化后的笔记，不是厨房实测结果。
- 新增中文菜以 1–2 人份为主，原有部分保留 4–6 人份；未实现自动份数缩放。新增份数、总耗时有编辑估计，已明确标注；土豆丝原版总时长 60 分钟。
- 营养是原作者估算，部分菜未展示数值。来源、版本差异和使用条件见 [来源记录](docs/RECIPE_SOURCES.md)。
- 清单只记种类，不记重量、保质期；不自动推断替代食材。过敏筛选根据列出的原料与部分复合调味品规则，无法保证品牌配方或交叉接触安全，实际仍需核对包装。
- 本地保存仅限同一浏览器、同一来源地址；清理网站数据会丢失，不跨设备同步。
- 计时不保证锁屏/后台声音、通知或屏幕常亮。不提供离线安装或断网首次加载。
- Chromium 模拟手机尺寸通过不等于 iOS/Android 真机测试，用户仍需在实际手机检查触控与课程演示网络。
- 拍照识别、模型训练、账号、社区、原生打包和公开发布不在本轮范围。

## 文件结构

`src/recipes.js` / `src/extra.js` / `src/chinese-recipes.js`：菜谱与来源；`src/preferences.js` / `src/Settings.jsx`：饮食偏好；`src/TimerWidget.jsx`：悬浮计时器；`src/logic.js`：匹配、搜索、存储校验；`src/main.jsx`：页面；`src/style.css`：样式；`tests/`：规则与浏览器验收。

内容更新后运行 `node scripts/source-ledger.mjs` 重建来源清单，并核实新增来源，不要用脚本生成的记录代替真实核对。

中文资料、配料角色及下一步产品建议见 [研究报告](docs/CHINESE_RECIPE_RESEARCH.md)。本轮采用开火前备菜/兑汁、分阶段计时、时间加状态判断；后续候选包括份数调整、单位说明和有依据的替代食材。
