## 1.9.4 课堂操作

- 安卓直接覆盖安装 `releases/xiaozao-1.9.4-debug.apk`。已运行的 Windows 1.8.0 服务可继续使用原地址。
- 同一餐切菜会分别保存步骤。新建饭友圈草稿后，刷新或返回编辑页可继续填写。香港繁体下可直接搜索菜谱显示名，采购清单也可按当前语言复制。
- “我的 → 厨房设置”可选择简体或香港繁体，内置食谱和本机搜索可离线使用。社区原文、已有下载和账号数据保留。线上饭友圈搜索仍使用服务器原有匹配。
- 饭友圈发现页首道菜展示上传原图，输入关键词切换为紧凑结果。下载后原位打开离线菜谱。“我的菜谱”默认显示已下载，可切换草稿与发布记录。编辑分基本信息、食材和步骤三段。成功发布和修订会保存离线副本；正在使用的旧副本可在结束跟做后更新。本机发布记录可找回已删除下载的公开作品。
- 顶栏采用 C 扁隶字标；悬浮计时器直接显示倒计时、暂停状态，支持原有拖动与长按隐藏。

## 当前功能

- 手动／批量添加食材，别名归一、去重、常用食材与常备调料；自定义食材可匹配已下载菜谱，牛肉卷可保留原名或手动关联肥牛片。
- 根据已有主料推荐齐料或缺 1–2 样的菜。“不限食材”是不指定必须用到哪种已有食材，仍按库存推荐；选择某种食材后只保留用到它的推荐。
- 菜名、食材与别名跨分类搜索；收藏、分类、时间、难度、少配料和饮食限制筛选。
- 菜篮排序、备料、采购清单和顺序建议；当前一餐保留菜单快照，返回／刷新保留进度，误点完成可恢复待做。
- 整页／分步跟做，有依据才显示本步用量、火力和状态；不强制勾选备料。
- 全局悬浮计时器可拖动、长按隐藏、设置恢复；暂停、加时、前台响铃及试听／关闭。隐藏不结束计时。
- 可选跟做常亮与失败提示、本地保存。A「小字蒸汽锅」标志，轻量顶部栏；底部可进入我的食材、找菜谱、菜篮、饭友圈和我的。
- 原有暖白、番茄红、深棕与现有菜品照片；安卓安全区和手机横竖屏适配。

## 饭友圈

已下载的菜谱支持离线删除本机副本。删除会同步移出菜篮，保留收藏与社区原作；使用中的跟做、一餐或菜谱计时结束后可删除。

- 用户名／密码注册登录，免登录浏览和下载。
- 结构化菜谱、图片与草稿，作者修改删除；用户分享与内置内容明确区分。
- 下载图片和指定版本后离线跟做、加入菜篮，可靠识别食材后参与推荐；更新需主动操作。
- 评论、单层回复、举报和管理员移除。
- 手动备份／恢复食材、调料、常用顺序、收藏与偏好，不自动覆盖本机配置。

Windows 一键部署见[教程](docs/WINDOWS_SERVER.md)，页面行为见[交互约定](docs/COMMUNITY_INTERACTIONS.md)。

## 安装与运行

附件为 `xiaozao-1.8.0-debug.apk`、Windows 一键部署 ZIP 和 SHA-256 文件，Android 7.0+ 可安装。沿用原测试签名，可覆盖旧测试版本；不要先卸载，以免丢失本地数据。这是课堂演示测试包，非商店正式签名包。

开发与服务运行需要 Node.js 24+：

```sh
npm ci
npm run dev
```

生产构建／预览：`npm run build`、`npm run preview`。安卓构建：`npm run android:apk`；项目本地 JDK 21 与 SDK 36 已就绪，见[安卓说明](docs/ANDROID.md)。

## 验证与限制

300 道开发版通过 **109 项单元／服务端测试与 518 项生产浏览器测试**，并在安卓 15 模拟手机上验证了覆盖安装、断网备料和删除。此前 1.7.0 发布包的结果也保存在[测试记录](docs/TEST_REPORT.md)。

```sh
npm test
npx playwright install chromium
npm run test:e2e
```

- 手机浏览器模拟不等于安卓真机验收；厂商桌面、真实扬声器及后台行为仍待确认。
- 后台／锁屏提醒、拍照识别、自动同步尚未实现。网页没有应用外壳离线缓存；APK 可首次离线打开内置内容，完整下载的用户菜谱也可离线使用。
- 全部 300 道目前没有营养估算值，也未由项目逐道下厨验证。用量、耗时和配方包含编辑取舍。
- 库存只记种类，不记重量、保质期；过敏筛选不能替代包装与交叉接触检查。
- 本机数据在卸载或清理后会丢失；手动配置备份不含下载文件、草稿、一餐进度与计时器。服务电脑另需备份。
- 照片与做法逐项署名，公开来源不等于无限转载授权。部分照片用于非商业课程演示，商业使用须另核对许可，见[来源清单](docs/RECIPE_SOURCES.md)与[200 道研究](docs/EXPANDED_200_RESEARCH.md)。
