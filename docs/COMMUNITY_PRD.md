# 饭友圈首版决策记录

2026-11-18，用户确认采用十个问题中的推荐方案，并补充课堂环境。**已纳入 1.7.0 实现**。需求已整合进[主 PRD](PRD.md)，以主 PRD 为统一依据；本文件不再维护独立需求副本。

| 问题 | 确认结果 |
| --- | --- |
| 1. 完成程度 | 课堂展示优先，关键流程真实可用，保留扩展空间 |
| 2. 社区形式 | 菜谱分享与围绕菜谱的讨论 |
| 3. 社交功能 | 评论和单层回复；暂不做点赞、关注、私信 |
| 4. 注册浏览 | 用户名／密码注册；免登录浏览、下载，发布／评论／备份需登录 |
| 5. 菜谱创建 | 结构化表单、本地草稿；用户分享与内置核对内容明确区分 |
| 6. 下载用途 | 离线跟做、加入菜篮，并在可靠匹配条件下参与食材推荐 |
| 7. 更新删除 | 主动更新，保留下载版本；作者删除不移除已有本机副本 |
| 8. 同步范围 | 手动备份／恢复配置；不自动合并，不同步计时和当前一餐 |
| 9. 内容管理 | 发布即公开，支持举报和管理员移除 |
| 10. 展示环境 | 2026-11-20；Windows 11、16 GB、RTX 3060；≤10 人；教室 Wi-Fi，热点备用 |

后端采用 Node.js、SQLite 和图片目录，Windows 包使用 Cloudflare 临时 HTTPS 通道；[页面交互约定](COMMUNITY_INTERACTIONS.md)先于实现写入。实现细化及验收要求见主 PRD，实测结果与部署边界见最新测试记录。
