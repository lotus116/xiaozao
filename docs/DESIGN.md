# 界面与工程决策

手机优先的「小灶」厨房助手，React + Vite 静态应用，无服务器依赖。规则和内容独立于视图，localStorage 保存带版本的状态。

颜色：米白 #faf9f5、纸白 #ffffff、锅绿 #254c3b、文字 #24372e、次要文字 #657268、提示黄 #f2df9c。中文使用系统苹方/微软雅黑；标题使用系统宋体增强食谱笔记感。避免外部字体和远端菜品图的网络、版权依赖。

布局：窄屏单列，宽屏两栏（食材工作台 / 推荐列表）。食材以可切换标签呈现，推荐使用分隔列表；只有当前任务使用突出按钮。详情独立页面，备料和步骤有明确进度。底部三个入口：我的食材、找菜谱、收藏。

辨识点：菜谱列表用小幅实拍区分成品，详情可查看完整画面与署名。没有对应实拍的菜采用文字版式。主要按钮至少 44px，页面支持缩放和减少动画。

内容：优先按原版份数保留用量，不自动缩放烹调时间；营养只展示原作者每份估算。水作为操作用水单列，不要求用户登记水库存。现阶段不宣称离线缓存、锁屏通知或项目试做。
