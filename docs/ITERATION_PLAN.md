# 第二轮改进：更贴近家庭做饭

2026-11-05，依据用户六项反馈。用户已选择推荐的饮食偏好方案：过敏严格排除，普通忌口可隐藏或提醒。

- [x] 中文菜谱：子代理检索国内中文来源，新增至少 25 道多样菜肴，记录来源与配料作用；有依据地简化现有菜谱，步骤同步调整。
- [x] 常备调料：显式显示自动记忆，可在设置管理；清空本次食材时保留调料。旧版清单/收藏迁移。
- [x] 分类：推荐、搜索和收藏区分菜肴、主食、汤羹，默认菜肴。
- [x] 随手计时：全局悬浮入口，自定义名称/时长、快捷时长、暂停继续、加一分钟、结束；刷新恢复。
- [x] 设置：常见过敏类别、复合调料提示、自定义普通忌口及隐藏/提醒。直接菜谱链接也应用过敏排除，不把可选过敏配料视作安全。
- [x] 实践研究：总结中文教学中的新手痛点、来源与采用/后续设计，避免堆砌未经证实的建议。
- [x] 验证：匹配放宽、分类隔离、调料长期保存、偏好过滤、计时恢复的规则与生产浏览器测试；布局截图及可访问性。
- [x] 本地 Git 保存，更新运行说明、来源与测试证据，汇报真实限制。无公开发布。

匹配规则修订：必需食材与基础调味参与匹配；来源支持可省的增香料/点缀不阻断“可以做”，逐项提示“可省”，不能仅通过把全部调料设为可选来增加结果。过敏过滤优先于可省规则。

设计保持既有风格，新增入口沿用原有按钮和色彩体系。计时器固定在导航上方，弹层可收起、不覆盖底部导航；表单和操作保留滚动空间与键盘焦点。
