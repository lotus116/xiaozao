# 把小灶带到灶台旁

2026-11-06。沿用米白、锅绿、中文家常菜笔记风格，保持 99 道菜与少操作路线。本轮目标是减少真实做饭时的遗漏和中断，不增加账号、社区、联网 AI 或强制勾选。

## 已落地

1. **开火前准备**：详情与备料页提供一眼能读完的准备提醒。按实际食材补充生熟分开、妥善冷藏熟饭、淀粉水使用前再搅匀；没有打勾或开做门槛。
2. **内容修正**：11 道菜纠正遗漏清水量、开火后切配、分油与火力、冷藏腌肉、淀粉水和可选肉末的熟度检查。见 [内容审计](COOKING_CONTENT_AUDIT.md)。ID、顺序与步骤数量不变，继续使用原有跟做进度。
3. **整页位置**：整页仍为默认。需要暂停时可点步骤序号记住位置，刷新、离开再回来或切换分步模式后仍在相应步骤；这是当前位置，不把前面的步骤假记为完成。
4. **屏幕常亮**：只在正在跟做时提供主动开启按钮，不默认开启、不保存此偏好。显示请求中、已开启、系统释放、失败和不支持的真实状态。切后台释放，回来仅在用户仍希望启用时重试；离开跟做释放，包括请求还没完成就退出的情况。
5. **计时可达**：跟做页能直接看到当前计时的名称、暂停状态和剩余时间。即使悬浮图标被隐藏也可以点此打开原计时，不创建覆盖它的新计时。前后台与 pageshow 时按时间戳刷新。
6. **随手小抄**：折叠的量勺/火候/计时提示说明毫升不总等于克、咸味调料先少放、份数增加不代表时间和火力翻倍、参考时间不等于熟度。菜篮提供可选的一锅多菜顺序说明，不自动虚构多锅调度。

## 研究如何影响取舍

查阅日期：2026-11-06。公开产品功能是参考，不代表这些功能已经在小灶实现。

- [Paprika 官方 iOS 使用说明](https://www.paprikaapp.com/help/ios/)：保留烹饪位置、配方用量和有名称的计时工具。本轮借鉴可恢复的位置及清楚的计时归属；不照搬逐项勾选、不声称已经支持多计时器或自动份量换算。
- [Kitchen Stories App](https://pages.kitchenstories.com/en/app)：分步骤做饭模式说明聚焦做饭场景的重要性。小灶保留用户选择的整页默认与可选分步，不强迫每一步翻页。
- [The Woks of Life 一锅多菜](https://thewoksoflife.com/how-to-cook-chinese-meal-one-wok/)：开火前洗切、配汁、准备盛盘，淀粉料汁使用前搅匀。本轮转为简短提醒和具体菜谱改正，不增加准备打勾清单。
- [FoodSafety.gov 食品安全四步骤](https://www.foodsafety.gov/keep-food-safe/4-steps-to-food-safety) 与 [FDA Safe Food Handling](https://www.fda.gov/food/buy-store-serve-safe-food/safe-food-handling)：清洁、生熟分离、充分加热、及时冷藏。提示不能替代食品温度计或包装要求。
- [FoodSafety.gov 安全中心温度表](https://www.foodsafety.gov/food-safety-charts/safe-minimum-internal-temperatures)：保留禽肉 74°C、肉末 71°C 等对应规则，不将一条温度套用到所有食材。
- [MDN Screen Wake Lock](https://developer.mozilla.org/en-US/docs/Web/API/Screen_Wake_Lock_API) 与 [Page Visibility](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API)：常亮可能被系统释放，后台回调会被节流。实现生命周期处理，界面不承诺锁屏/后台准时响铃。

## 明确没有做的事

- 没有把资料核对或浏览器测试写成真实下厨试做，仍需用真实锅具与食材验证。
- 没有未经核对把所有“少许/适量”换成精确克数，也没有机械倍增份数或加热时间。
- 仍为一个全局计时器、页面内到点提醒，无音效、系统通知或后台服务。长炖同时设手机系统计时器，不能离锅无人照看。
- 常亮依赖浏览器、HTTPS/安全上下文和系统支持。局域网 HTTP、WebView 或某些手机可能不支持；不支持时仍能正常跟做。
- 本轮只更新 Web 源码，不重打 APK，不部署网站。旧 APK 不包含本轮改动。

## 验证方法

规则测试覆盖内容修正、针对性提醒、计时名称/显示、常亮取消/失败/系统释放与异步竞态。浏览器回归覆盖99道菜入口、整页书签、隐藏计时、常亮各状态、回退与刷新、320–1280px布局和自动可访问性。常亮成功/拒绝/释放用隔离 API 模拟验证控制流程，不能当成手机系统实测。最终数字见 [测试记录](TEST_REPORT.md)。
