# 99 道新手教学改写：范围与质量门槛

日期：2026-11-06。用户要求把现有 99 道菜都按“大厨带新手、成品好吃优先”的思路处理。本轮不新增菜，不把看起来精确的克数当成正确性，也不把流量、评分或软件测试等同于下厨试做。

## 分批边界

- 首批 3 道：番茄炒鸡蛋、家常蒸蛋、家常蛋炒饭。见 [首批研究](BEGINNER_RECIPE_RESEARCH.md)。
- 蔬菜与豆制品 A 组 23 道：见 [A 组来源与逐菜取舍](TEACHING_VEGETABLES_A.md)。
- 蔬菜与豆制品 B 组 23 道：见 [B 组来源与逐菜取舍](TEACHING_VEGETABLES_B.md)。
- 肉类、鱼虾及含肉可选项 21 道：见 [肉类组来源与逐菜取舍](TEACHING_PROTEIN.md)。
- 主食与汤羹 29 道：见 [主食汤羹组来源与逐菜取舍](TEACHING_STAPLES_SOUPS.md)。

当前 99 道共提供 201 条具体补救。42 道原链接本轮未能完整重读，按菜公开说明；独立补充来源有的只支持相关技法或食安事项，不能称为全部 99 道完整配方多源验证。

这只是编辑分工，不是应用中的新分类。应用继续使用原有菜肴、主食、汤羹分类。

## 每道必须完成的检查

1. 原料与步骤一致。可选料没有也能按步骤完成，水不变成采购门槛，提到的新原料需列入用料。量词能灵活，但关键蛋水比、煮饭用水、肉类安全温度不能随意省略。
2. 主步骤能独立跟做，包含准备时机、火力观察、什么时候进入下一步、什么时候需要继续加热。不能把关键熟度要求藏在折叠帮助里。
3. 一句抓重点，说明这道菜最值得注意的事；用量调整按这道菜解释。至少两条具体问题与补救，不把相同“少盐多尝”模板贴满 99 道。
4. 计时是观察节点。锅具、食材厚度、份量和设备不同，时间可能变化；涉及肉类时外观不能代替安全中心温度。不要用“零失败”“保证嫩滑”“已实测”包装未实做内容。
5. 公开来源保持归因，补充独立方法核对。某些美食天下原链接本轮不可读，保留原记录并在对应菜说明限制，不绕过验证，也不把旧记录当本轮重新读过。
6. 可见评分、点赞、做过人数与具体读者评论分别记录。只把真实读到的证据归于对应页面，不称“全网最火”，不把全部 99 道都冒称实时高赞榜单选品。
7. 不复制作者完整表达、故事、图片或视频。公开页面不等于转载许可；本项目写的是重新组织的简要教学笔记，公开发行前仍需核实使用条件。

## 保持原有做饭体验

- 无新账号、网络依赖或强制打勾，延续整页跟做、可选分步和厨房计时。
- 每菜保留 id、分类、原步骤数量、标题、索引和计时秒数；兼容旧版已保存的步骤位置、整餐状态和进行中的计时。
- 数值与时间是参考，不通过扩大卡片数字或增加一串确认步骤来制造“专业感”。
- 增加的调整/补救默认折叠；关键动作仍在主步骤里。
- 菜篮排序是另一个功能边界。排序建议只使用有步骤证据的资料，证据失效或未知时保留原相对顺序，不凭菜名猜测，不改当前正在做的一餐。

## 验证边界

- 内容静态检查：99 道全覆盖、提示完整且聚焦语句不重复、来源结构、可选原料语义、旧步骤与计时签名一致。
- 状态回归：每道从备料到完成的合法位置均可恢复，收藏、食材、菜篮和整餐状态不被改写清空。
- 浏览器回归：所有菜详情、备料、整页/分步入口；小屏布局、折叠帮助、旧计时与中断状态；既有功能的完整回归。
