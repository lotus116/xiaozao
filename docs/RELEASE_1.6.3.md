# 小灶 v1.6.3 阶段发布

这是联网社区开发前的离线做饭助手阶段版，用于课堂演示。应用实现基线为 dc7aabb；发布标签另包含文档同步和未确认的下一阶段讨论稿，没有社区代码。

## 功能

200 道、625 步，照片、来源、用量和教学随包提供；食材推荐、跨分类别名搜索、收藏、饮食限制、菜篮与连续跟做。完成进度保留、恢复待做、未知食材标记；悬浮计时与长按隐藏、前台响铃；A 蒸汽锅标志和轻量顶部工具栏。
