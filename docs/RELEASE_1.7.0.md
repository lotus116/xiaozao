# 小灶 v1.7.0 · 饭友圈课堂测试版

在 1.6.3 离线做饭助手上增加饭友圈，保留内置 200 道菜、原配色、菜篮进度、前台响铃和悬浮计时器／长按隐藏。

## 新功能

- 用户名／密码注册登录；游客浏览和下载，登录后发布、评论、举报及备份。
- 带图结构化菜谱与本机草稿；作者编辑删除，用户分享单独标识。
- 下载图片和指定版本后离线跟做、加入菜篮；可靠匹配食材后参与推荐。更新由用户主动操作，正在使用的菜谱不替换。
- 菜谱评论、单层回复、举报和管理员处理。
- 手动备份／恢复食材、调料、常用顺序、收藏和偏好，不自动覆盖一餐进度或计时器。

## 下载

- `xiaozao-1.7.0-debug.apk`：Android 7.0+，versionCode 13，沿用旧测试签名，可覆盖安装；不要先卸载旧版。
- `xiaozao-1.7.0-windows-x64.zip`：Windows 11 x64 一键部署包，自带运行环境、数据库支持、HTTPS 通道和教程。
- 各附件配有 `.sha256` 校验文件。

Windows 完整解压后双击 `Start.cmd`，保持服务与网络窗口运行。把网络窗口给出的 HTTPS 地址填入 App 的“饭友圈 → 账号 → 服务地址”。管理员密码在首次启动时于本机生成，不能分享给同学。部署目录必须保留，其中 `server-data` 是实际数据。

[Windows 完整教程](https://github.com/lotus116/xiaozao/blob/v1.7.0/docs/WINDOWS_SERVER.md) · [页面与交互约定](https://github.com/lotus116/xiaozao/blob/v1.7.0/docs/COMMUNITY_INTERACTIONS.md)
