# 1.7.0 交付审查

2026-11-18。本次为实现后的自查与自动测试，不冒充独立第三方安全审计。

## 已检查并修复

- 权限：发布、修改、评论、举报、私有备份和管理员操作由后端鉴权；不能通过前端隐藏按钮代替授权。管理员本机创建，公开注册不能抢占保留名。密码 scrypt，会话令牌哈希落库并支持退出失效。
- 并发：菜谱更新带版本条件，两个旧版本请求不能互相覆盖；发布和评论使用操作编号避免重复提交。10 个独立用户并发读取／评论测试通过。
- 本机数据：下载图片解码成功后才事务保存；失败不留下半份菜谱。服务 ID 与菜谱 ID 共同标识副本；作者删除不影响已下载内容。
- 版本与计时：一餐、未完成跟做、计时中的菜谱禁止替换；保存期间若开始使用则保留旧版。完成单道菜后允许更新，但清除旧版步骤位置，防止误套到新版。
- 账号与备份：首次登录不自动覆盖；切换服务撤销旧请求并清凭证；草稿按账号／服务隔离。恢复只覆盖明确字段，一餐、下载与计时保留；写入失败不显示成功。
- 交互：错误提示获得焦点，发布失败保留草稿；社区图片来源可聚焦，举报页显示可读内容。第五个导航入口仍满足小屏触点，悬浮长按隐藏保留。
- 回归准备：异步读取下载库后，旧测试需等待初始化完成再写测试数据；保留业务断言，仅将四入口断言更新为已约定的五入口，没有跳过测试。

## 部署与仍需验证

Windows 包不包含真实数据库、管理员密码、会话、开发签名密钥或 node_modules。Node 与 cloudflared 来自官方发行，按官方 SHA-256 验证；附许可证、运行脚本及备份教程。测试数据只在临时目录创建。

Mac 自动测试、ZIP 内容和同一服务代码验证不能证明 Windows 启动器、厂商安卓系统、手机扬声器及课堂网络表现。这些必须在演示设备实测；不把临时通道描述为正式长期服务。现有 Android lint 5 项警告与前端主包体积提示保留，生产依赖审计未发现已知漏洞。
