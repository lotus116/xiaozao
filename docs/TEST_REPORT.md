## 调试与修复

- 默认 npm/浏览器缓存目录不可写：改用临时缓存，不更改用户目录所有权。
- 测试浏览器初次启动受系统进程权限限制：通过已授权的本地浏览器测试权限运行。
- 计时周期更新期间，原来在 App 内声明的菜谱组件会重新挂载：提取为顶层组件，避免按钮焦点丢失；没有计时器时不启动更新循环。
- 27 道菜合并为一个用例的首次验证超时：排查显示哈希导航后测试在备料列表挂载前就取 `.all()`，得到空集合。修正为先等待用量复选框数量，再逐项点击，同时拆成独立用例，失败可定位至具体菜谱。修复后 27 条全过。
- 内容扩充后更新搜索/数量期望，生产构建回归全部通过。
