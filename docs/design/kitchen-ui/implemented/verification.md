# 小灶界面调整 · 运行验收

[同数据前后对照](comparison.webp) · [操作过程与减少动态效果对照](interaction-preview.gif)

本次从生产构建的 JavaScript 和 CSS 运行实际 React 界面，使用独立 macOS WebKit 和仓库菜图。食材、收藏、菜篮、下载样例和草稿都在临时数据环境中。构建入口为 `index-BKJJLghL.js`，样式为 `index-CIhMeRRu.css`。表中尺寸为 CSS 像素，纵坐标从可见页面顶端计算。

| 核验 | 实际结果 |
| --- | --- |
| 320×568 找菜 | 空食材时在首条番茄炒鸡蛋的加菜篮中心 (282,415) 点击，加入成功；收藏中心也命中收藏。向下滚动后第六条蒜香拍黄瓜的中心点击加入成功。回到顶部取消番茄炒鸡蛋后，篮内只剩蒜香拍黄瓜。 |
| 计时器 | 搜索页按钮实际命中区 48×48。滚动后，(282,32) 能打开计时，收起后仍在原滚动位置。拖动产生 WebKit 确认过的 pointerdown、pointermove、pointerup，拖后位置成功保存，右侧加篮仍可点。长按隐藏后可从设置恢复。 |
| 清空与返回 | 汤羹分类中输入无结果的关键词，清空后仍选中汤羹，输入框保留焦点。由找菜打开内置菜谱，再用“返回菜谱”回到找菜页。 |
| 13 样缺料 | 香港繁体搜索“魚香肉絲”，320px 行高约 172→136，390px 约 135→129。列表呈现缺料总数与两种预览，仍能打开菜谱详情。 |
| 食材分栏 | 用同一组十种食材检查 759、760、768、800、801、844、900px。760px 切换双栏时录入栏 300px、推荐栏 389px。800→801px 的推荐栏由 428px 增至 429px。 |
| 排序与跟做 | 三道菜预览顺序、采用、开做、整页切分步、前进、后退，回到菜篮并继续时恢复到“先炒鸡蛋”。320×496 下，第 2 步指令从纵坐标 430 提前至 102，底部按钮区自 423 起；新版指令在 304 结束，用量在 381 结束。844×390 下，指令与用量同在纵坐标 103 开始，分别在 295 和 169 结束，底部按钮区从 317 开始。 |
| 社区与下载 | 测试账号之外的离线入口和规范发现页都显示“饭友圈”，右侧均收起全局找菜按钮。下载库使用样例番茄炒鸡蛋，通过“更多”打开管理底单，取消后焦点回到原条目的“更多”。 |
| 编辑器 | 320px 宽录入五对食材、用量，每次回车转至下一字段；添加第二步，再离开并重开原草稿，菜名、五对内容和上次打开的步骤页均恢复。 |
| 动效和适配 | 详情标准样式启用 `open-recipe`，模拟减少动态效果时为 `none`；标准底单使用 `open-panel`。动图采样两种模式的相同操作路径，含找菜、详情、菜篮、开做与切步。离屏绘制和动图采样影响动画细节，只能用于查看操作顺序及状态。 |

**仍需 Android 验收**：原生输入法弹出与收起、系统返回、系统字号及字体回退、物理触控、手感和动画帧率、系统栏安全区、跨进程持久化与亮屏能力。模拟减少动态效果测试使用生产 CSS 的相应媒体查询分支。社区样例没有访问真实服务。

生产构建及 Capacitor 资产同步通过。104 项不依赖监听端口的测试通过；社区服务的 6 项测试用内存传输运行，保留 SQLite、鉴权与数据持久化代码。常规 Playwright 运行所需的预览端口、Gradle 文件锁服务以及 ADB 监听在本环境受限。审查用 APK 在 1.9.3 原生包内替换前端，347 份构建资源逐项一致，已通过对齐和同证书签名校验。
