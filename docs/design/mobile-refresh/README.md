# 小灶安卓手机界面改版

## 现状与布局依据

390 × 844 触控预览见同目录 before 图。主页输入框与推荐空状态分开较远，常用食材入口藏在两个相似的折叠行中。搜索外壳宽 354 px，输入元素宽约 294 px，焦点线只围住后者。饭友圈没有配置服务时仍显示搜索，账号页同时突出连接、登录、注册。菜篮已有明确的空状态与开始操作。

## 实施与验收

| 板块 | 画面、操作和状态 | 验收 |
| --- | --- | --- |
| 我的食材 | 沿用小灶标识和暖白底，把已有食材、输入和可展开的配料工具收在浅米色备料区，推荐从下一个标题开始。已有跟做进度仍在输入以前。 | 展开后可添加食材，收起后选择保留；窄屏主操作可见。 |
| 找菜谱 | 标题后先放统一搜索框，分类在下方，筛选继续折叠。点击图标或空白处均聚焦，整框同一圈红线、不改变大小。 | 触屏与键盘均能看到焦点；搜索、切类、返回保留既有语义。 |
| 饭友圈 | 页首右侧发布，已连接时搜索在列表上方；菜图、菜名、作者和时长分层。未连接时集中呈现连接入口和本机菜谱入口。分栏只负责发现与个人菜谱。 | 发布仍按原路径登录再返回；离线能打开已下载菜谱；下载和版本元数据保留。 |
| 我的 | 底栏依次为我的食材、找菜谱、菜篮、饭友圈、我的。个人页顶部为账号入口，显示本机记忆的账号名或登录提示；下方为收藏、我的菜谱、厨房设置。收藏和下载显示各自真实数量。保留原设置快捷入口和旧链接。 | 登录前后都能用本机收藏和设置。账号、设置与收藏归属「我的」；安卓返回逐层退回。 |
| 菜篮与跟做 | 空菜篮提供找菜入口；有菜时沿用顺序和备料流程；悬浮计时独立于页面。底栏选中和按压反馈共用一套颜色。 | 计时器可打开、可长按隐藏。减少动态效果时去掉过渡。 |

设计稿用于检查信息顺序、分组和触点；菜名、照片、计数与账号状态以应用真实数据为准。不得把设计稿中的装饰字或样例状态写入运行数据。

## 设计审查与实装对照
